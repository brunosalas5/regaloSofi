📖 ¿CÓMO SE JUEGA?

Este es un crucigrama musical.

Cada número corresponde a una palabra que tenés que descubrir a partir de una pista.

Las palabras pueden estar en horizontal o vertical y se cruzan entre sí.

Completá todas las palabras y después comprobá tus respuestas.

Reglas:
  1. Cada casillero blanco corresponde a una letra.
  2. Los casilleros negros separan las palabras.
  3. Los números indican dónde comienza cada palabra.
  4. Las palabras pueden ser horizontales o verticales.
  5. Las respuestas se escriben sin espacios ni tildes.
  6. Podés seleccionar una pista para encontrar rápidamente dónde escribir.
  7. Cuando hayas completado todas las palabras aparecerá el botón para comprobar el crucigrama.
  8. Si hay errores, las respuestas incorrectas se marcarán visualmente para que puedas corregirlas.
  9. Cuando todas las palabras sean correctas, se mostrará la pantalla de victoria.
